# Plan 8.2: Landscape Optimization & Pinch-to-Zoom

## Objective
Address mobile accessibility issues where images feel too small in landscape orientation and lack native pinch-to-zoom functionality.

## Context
- src/components/coastal/Lightbox.tsx
- .gsd/phases/8/DEBUG.md

## Tasks

<task type="auto">
  <name>Implement Pinch-to-Zoom & Pan</name>
  <files>
    <file>src/components/coastal/Lightbox.tsx</file>
  </files>
  <action>
    - Add state for `scale` (zoom level) and `offset` (pan position).
    - Implement touch event handlers (`onTouchStart`, `onTouchMove`, `onTouchEnd`) to detect pinch gestures (two fingers) and calculate distance change.
    - Update `scale` based on pinch distance.
    - When `scale > 1`, disable the carousel swipe gesture and enable panning.
    - Add a "Double Tap" shortcut to toggle zoom (1x to 2x).
    - Ensure zoom resets when navigating between images.
  </action>
  <verify>Check touch event logic and ensure no conflicts with existing carousel swipe.</verify>
  <done>Users can pinch to zoom images and pan when zoomed. Double-tap also zooms.</done>
</task>
