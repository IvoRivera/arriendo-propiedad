## Lessons Learned
- **Dependency Isolation**: Pinned exact versions (no `^`) are critical when working with bleeding-edge stacks like Next 15 / React 19 to avoid peer dependency drift.
- **Defensive Root Scripting**: Mobile wallet browsers (Coinbase/Trust) can crash modern Next.js apps by injecting malformed `window.ethereum` objects. A root layout "Bug Guard" is a necessary safety measure.
- **Library Evolution**: `react-day-picker` v9 customization requires moving from `DayContent` to `DayButton` patterns.
- **Hydration Safety**: `createPortal` is the most reliable way to handle high-complexity modals on mobile Safari to prevent z-index and hydration issues.
